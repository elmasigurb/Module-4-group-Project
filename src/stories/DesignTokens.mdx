# Design tokens

All colors, fonts and spacing are CSS variables in `src/styles/tokens.css`.
This page reads the variables directly, so it always shows the current values.

> Synced with the Figma file (Hi fi page and **Kvitt · Viðmótseiningar**).
> Figma has no variables, so the values were read from the components themselves.
> The desktop-only values (`--color-bg-desktop`, sidebar, desktop title sizes) are our own extension.

### Mono: `--font-mono`

Used for numbers, dates and amounts (the `.mono` class).

<Typeset
  fontFamily="var(--font-mono)"
  fontWeight={400}
  sizes={['var(--text-xs)', 'var(--text-sm)', 'var(--text-md)']}
  sampleText="34.490 kr. · 11.08.2026"
/>

| Token       | Size / line height | Use                                          |
| ----------- | ------------------ | -------------------------------------------- |
| `--text-xs` | 12 / 16            | Field labels, dates, nav labels              |
| `--text-sm` | 14 / 20            | Card rows, search, amounts                   |
| `--text-md` | 16 / 24            | Buttons, inputs, card and section titles     |
| `--text-lg` | 24 / 32            | Page titles on mobile                        |
| `--text-xl` | 32 / 40            | Logo (Fira Code), page titles on desktop     |

Weights: 400 regular, 500 medium (field labels), 600 semibold (titles, buttons).

## Layout

| Token                 | Use                                        |
| --------------------- | ------------------------------------------ |
| `--page-gutter`       | Side padding of content on mobile (24px)   |
| `--nav-height`        | Height of the bottom navigation on mobile  |
| `--sidebar-width`     | Width of the sidebar on desktop (≥ 900px)  |
| `--content-max-width` | Max width of page content                  |
| `--form-max-width`    | Max width of forms (`.page--narrow`)       |

Breakpoints can't be CSS variables in media queries, so they are fixed: **tablet ≥ 640px**, **desktop ≥ 900px**.
